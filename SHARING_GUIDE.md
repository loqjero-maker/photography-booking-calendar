## For Android Users

### Option 1: Open in Browser (EASIEST)
1. Open Chrome, Firefox, or any browser on your Android
2. Go to: `https://loqjero-maker.github.io/photography-booking-calendar/`
3. Bookmark it (tap menu → Star)
4. Done! Add to home screen if you want an app icon

### Option 2: Add to Home Screen (Like an App)
1. Open in browser: https://loqjero-maker.github.io/photography-booking-calendar/
2. Tap menu (3 dots) → "Add to Home screen" or "Install app"
3. Tap "Add"
4. Calendar now appears as an app icon on your home screen!

---

## For Windows Users

### Option 1: Open in Browser (EASIEST)
1. Open Edge, Chrome, or Firefox
2. Go to: `https://loqjero-maker.github.io/photography-booking-calendar/`
3. Bookmark it (Ctrl+D)
4. Done!

### Option 2: Pin to Start Menu (Like an App)
1. Open in browser: https://loqjero-maker.github.io/photography-booking-calendar/
2. Click the menu (⋯) 
3. Click "App and more" → "Install this site as an app"
4. Calendar is installed and appears in Start menu!

### Option 3: Create Desktop Shortcut
1. Open in browser
2. Right-click the address bar
3. Select "Create shortcut"
4. Name it "Photography Calendar"
5. Shortcut appears on desktop!

## Troubleshooting

**Q: Calendar won't load?**
- Check internet connection
- Try refreshing (pull down on Android / F5 on Windows)
- Try a different browser

**Q: Can't find the link?**
- Look in your browser history
- Use the QR code
- Copy: `loqjero-maker.github.io/photography-booking-calendar`

**Q: Want to edit availability?**
- Only YOU can change your schedule in "Manage Availability" tab
- Your friends can only view & book
